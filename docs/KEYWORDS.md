## 仓库内兜底搜索

GitHub 仓库页按 `/` 聚焦搜索框，例如：

```
repo:<用户名>/<仓库名> "404 NotAuthorizedOrNotFound"
repo:<用户名>/<仓库名> journalctl path:docs/posts/
```

GitHub 不索引 Pages 生成的网页，但会索引仓库默认分支里的源文件，所以 `.md` 原文一定搜得到。`content:` 限定只搜内容，`path:` 限定目录，`""` 做精确短语匹配。
