# 折腾笔记

> 给自己看的排障手册。目标只有一个：**以后遇到同样的问题，30 秒内翻到那一篇。**

## 怎么找东西

| 方式 | 什么时候用 |
| --- | --- |
| 左上搜索框 | 记得报错原文、命令、型号时，直接搜 |
| [关键词速查表](KEYWORDS.md) | 只记得个大概症状，先看关键词对照表 |
| 左侧边栏 | 按分类翻，目录是自动生成的，不会漏 |
| GitHub 仓库搜索 | 网页打不开 / 站内搜不到时，用 `repo:用户名/仓库名 关键词` 兜底 |

## 这个站点的三条规矩

1. **一篇文章 = `posts/` 下一个文件夹**，里面放 `README.md` 和它自己的 `images/`。
   删掉整个文件夹，其他页面一点不受影响（跑一次工具重建目录即可）。
2. **`docs/_sidebar.md` 和 `docs/KEYWORDS.md` 不要手改**，它们由仓库根目录的
   `双击打开.bat` 自动生成。你只管写文章。
3. **想改页面长相**，只动 `docs/index.html` 里那段标了「外观修正区」的 `<style>`，
   不会碰到任何文章内容。

## 写新的一篇（推荐）

双击仓库根目录的 **`双击打开.bat`** → 选 `1`，按提示填标题、分类、关键词和英文文件夹名。
工具会自动建好文件夹、写好模板、重建目录。然后：

```powershell
git add .
git commit -m "add: xxx"
git push
```

> 不习惯工具也可以手工来：复制 `posts/_template/` 整个文件夹 → 改名 → 改 `README.md` 顶部的
> `<!-- meta ... -->` → 双击工具选 `2` 重建目录。

## 图片怎么写

图片放进**这篇文章自己的 `images/` 文件夹**，正文里写：

```markdown
![配图说明](images/xxx.png)
```

路径永远是 `images/文件名`，不用带文件夹名，也不用 `../`。工具会帮你检查图片是不是真的存在。

## ⚠️ 公开警告

GitHub Free 的 Pages 只能挂在 **public** 仓库上，而且**生成的网页任何人都能访问**；即便以后升级到 Pro 把仓库设成私有，站点依然是公开的。所以：

- 不写 OCI 的 OCID、租户名、邮箱、API 私钥、密钥指纹
- 不写黑苹果的序列号、ROM、MLB、SystemUUID、Apple ID
- 不贴未打码的控制台截图、不写真实 token

统一用 `<OCID>`、`<SERIAL>`、`<TOKEN>` 这类占位符代替。
